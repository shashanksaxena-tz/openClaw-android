Can you explain how Kotlin coroutines work and show me a simple example?
OpenClaw
Kotlin Coroutines are a way to write asynchronous code that looks sequential. They're built on suspend functions and coroutine builders.

Here are the key concepts:
• suspend — marks a function that can be paused
• launch — starts a new coroutine (fire & forget)
• async — starts a coroutine that returns a result
import kotlinx.coroutines.* fun main() = runBlocking { val result = async { fetchData() } println("Got: ${result.await()}") } suspend fun fetchData(): String { delay(1000) // non-blocking return "Hello!" }
